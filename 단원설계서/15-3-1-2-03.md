- 교육과정 범위 (넘지 않을 선)
  - 부피비는 정수비 관찰·해석까지. **아보가드로 법칙이라는 이름, 몰, 기체 법칙(보일·샤를) 수식 계산, 분자량으로 질량 구하기는 다루지 않음.** "일정한 온도와 압력에서 같은 부피 속 분자 수는 같다"는 교과서 날개 글 수준으로만.
  - 온도·압력 값은 바꾸지 않음(조작 변인이 아님). 수증기의 응결은 "실온에서 물(액체)이 되어 부피가 거의 없다"는 정성적 설명까지.
  - 질량비(일정 성분비)는 앞 소단원(`15-3-1-2-01`) 내용이므로 "부피비와 질량비는 다르다"를 짚는 데에만 씀(계산 없음).
- 차시 목표 (학생이 이 활동 후 할 수 있는 것)
  1. 물 합성 장치 실험에서 반응 후 남은 기체의 부피를 측정하고, 반응한 수소 기체와 산소 기체의 부피비가 2 : 1임을 찾을 수 있다.
  2. 생성된 수증기가 실온에서 응결하므로 남은 기체는 반응하지 않은 기체임을 설명할 수 있다.
  3. 수증기·염화 수소·암모니아 생성 반응에서 기체의 부피 사이에 간단한 정수비가 성립함(기체 반응 법칙)을 설명할 수 있다.
  4. 기체끼리의 반응에서 화학 반응식의 계수비 = 분자 수의 비 = 부피비임을 부피 상자 모형으로 설명하고, 암모니아 분자 모형을 빈 상자에 알맞게 나타낼 수 있다.

## 교과서 요약 (이미지 대신 이 글을 기준으로 작업)
- 30쪽
  - 미리 조사하기 「화성에서 물을 만들 수 있을까?」: 화성에 고립된 우주인이 감자 재배에 쓸 물을 얻으려고 우주선 연료로 쓰이는 물질을 반응시킨 소설 이야기. 무엇을 반응시켰는지 조사(삽화: 돔 온실 안에서 우주복 차림 인물이 감자 줄기를 양손에 들고 웃음).
  - 도입 문장 요지: 수소와 산소가 반응해 수증기가 될 때 일정한 질량비로 반응한다. 질량비 말고 또 다른 규칙성이 있는지 알아보자.
  - 배움활동 「수소 기체와 산소 기체의 반응에서 규칙성 찾기」
    - 목표: 수소 기체와 산소 기체의 반응에서 규칙성을 찾고 설명할 수 있다.
    - 준비물: 물 합성 장치, 수소 기체, 산소 기체, 주사기 2개, 실험복, 보안경, 실험용 고무장갑
    - 안전: 수소 기체는 가연성이므로 열로부터 멀리하고 환기가 잘 되는 곳에서. 물 합성 장치에 넣는 기체의 종류와 순서가 바뀌지 않도록 유의. (31쪽) 수소와 산소는 폭발적으로 반응하므로 안전에 유의, 점화기를 누를 때 피스톤이 사람을 향하지 않게.
    - 실험하기
      1. 물 합성 장치의 기체 주입구를 열고 주사기로 산소 기체 6 mL를 넣은 뒤 같은 방법으로 수소 기체 6 mL를 넣는다.
      2. 기체 주입구를 닫고 점화기를 눌러 반응시킨 뒤 남은 기체의 부피를 측정한다.
      3. 2의 장치에 수소 기체 6 mL를 넣고 주입구를 닫는다. 점화기를 눌러 반응시킨 뒤 남은 기체의 부피를 측정한다.
    - 사진 설명: 물 합성 장치는 가로로 누운 투명한 관(실린더)에 눈금자가 붙어 있고, 한쪽 끝에 기체 주입구(위로 솟은 꼭지)와 점화 전극, 다른 쪽 끝에 피스톤 손잡이가 있으며, 검은 받침대 두세 개가 관을 받침. 왼쪽 사진은 장갑 낀 손이 주사기를 주입구에 꽂아 기체를 넣는 장면(수소 기체·산소 기체 이름표), 오른쪽 사진은 전선으로 연결된 손잡이형 점화기를 엄지로 누르는 장면.
- 31쪽
  - 정리하기: 1. 실험하기 2와 3에서 남은 기체의 부피를 각각 쓰기. 2. 반응한 수소 기체와 산소 기체의 부피 사이 관계 설명하기.
  - 본문 요지: 일정한 온도와 압력에서 수소와 산소가 반응해 수증기가 될 때 반응한 수소 : 산소 부피비는 2 : 1. 수증기 부피까지 고려하면 수소 : 산소 : 수증기 = 2 : 1 : 2로 일정.
  - 그림 Ⅰ-12 수증기 생성 반응에서 기체의 부피 관계: 같은 크기의 투명 정육면체 상자로 '수소 2 부피 + 산소 1 부피 → 수증기 2 부피'.
  - 그림 Ⅰ-13 염화 수소 기체와 암모니아 기체 생성 반응에서 기체의 부피 관계: '수소 1 부피 + 염소 1 부피 → 염화 수소 2 부피', '질소 1 부피 + 수소 3 부피 → 암모니아 2 부피'.
  - 본문: 일정한 온도와 압력에서 기체들이 반응해 새로운 기체가 생성될 때 각 기체의 부피 사이에는 항상 간단한 정수비가 성립한다.
  - 게이뤼삭이 '온도와 압력이 일정할 때 반응하는 기체와 생성되는 기체의 부피 사이에 간단한 정수비가 성립한다.'는 것을 발견 → **기체 반응 법칙**.
  - 과학자 이야기: 게이뤼삭(Gay-Lussac, J. L., 1778~1850) 프랑스의 과학자, 몇 가지 기체 반응 실험으로 기체 반응 법칙 발견.
- 32쪽
  - 그림 Ⅰ-14 수증기 생성 반응의 화학 반응식과 부피 관계: 상자 2개에 수소 분자(작은 회색 공 2개) 1개씩, 상자 1개에 산소 분자(큰 빨간 공 2개), 상자 2개에 물 분자(빨간 공에 회색 공 2개가 굽게 붙음) 1개씩. 아래 띠 '2H₂ + O₂ → 2H₂O', 표: 계수비 2 : 1 : 2 / 분자 수의 비 2 : 1 : 2 / 부피비 2 : 1 : 2.
  - 본문 요지: 각 기체의 부피비는 반응물질과 생성물질의 분자 수의 비와 같고, 화학 반응식의 계수비와도 같다. 반응물질과 생성물질이 모두 기체이면 화학 반응식으로 부피비를 알 수 있으며 이는 분자 수의 비와 같다.
  - 날개 글 「기체의 부피와 분자 수」: 일정한 온도와 압력에서 모든 기체는 같은 부피 속에 같은 수의 분자가 들어 있다. 따라서 부피비와 분자 수의 비는 같다.
  - 활동+ 적용하기: 질소 + 수소 → 암모니아 반응 모형. 상자 1개에 질소 분자(큰 파란 공 2개), 상자 3개에 수소 분자 1개씩, '→' 뒤 빈 상자 2개. 아래 'N₂ + 3H₂ → 2NH₃'. 빈칸에 암모니아 분자를 그리고 까닭을 설명.
  - 배운 내용 정리하기: (1) 기체 부피 사이에 간단한 정수비가 성립하는 법칙 이름 빈칸, (2) 기체 반응의 화학 반응식에서 계수비는 각 기체의 ( ) 수의 비, ( )비와 같다.
  - 스스로 평가하기: 간단한 정수비 설명 / 계수비와 부피비 관계 설명 / 활동 참여.
- 쓰는 용어: 수소 기체, 산소 기체, 수증기, 염소 기체, 염화 수소 기체, 질소 기체, 암모니아 기체, 물 합성 장치, 기체 주입구, 주사기, 점화기, 피스톤, 부피비, 간단한 정수비, 기체 반응 법칙, 게이뤼삭, 화학 반응식, 계수비, 분자 수의 비, 일정한 온도와 압력

| 4 | 부피비가 2 : 1이면 질량비도 2 : 1이다(앞 차시 질량비 1 : 8과 혼동) | 실험 탭 기록표 아래 비교 글 "앞 차시에서 배운 질량비 수소 : 산소 = 1 : 8. 기록표로 찾은 부피비와 같을까요?"(부피비는 계산해 주지 않고 학생이 기록표에서 찾음). 탭 ② 비 표에는 부피비만 있고 질량은 나오지 않아 둘을 섞지 않게 함. 문항 7 보기로 확인 |
| 5 | 분자가 큰 기체는 같은 부피에 분자가 적게 들어간다 | 부피 상자 탭에서 모든 상자에 분자 모형이 1개씩 들어감(크기가 다른 산소·수소·암모니아 분자도 같음). 상자를 누르면 "일정한 온도와 압력에서 같은 부피 속 분자 수는 기체 종류와 관계없이 같아요(분자 사이 거리가 분자 크기보다 훨씬 멀어서)" 말풍선 |

- 계산 (화면에 나오는 수치와 공식·단위)
  - 점화 전 산소 부피 V_O₂, 수소 부피 V_H₂ (mL) = 지금 관 속에 있는 각 기체의 양(이전 점화에서 남은 기체 포함).
  - 기체 부피(눈금, mL) = V_O₂ + V_H₂ (점화 전), 점화 후에는 남은 기체 부피. 물(액체)의 부피는 0으로 봄.
  - 반응: V_H₂ ≥ 2 × V_O₂ 이면 산소가 모두 반응 → 남은 기체 = 수소, 남은 부피 = V_H₂ − 2 × V_O₂. 아니면 수소가 모두 반응 → 남은 기체 = 산소, 남은 부피 = V_O₂ − V_H₂ ÷ 2. 둘 다 0이 되면 남은 기체 '없음', 피스톤 0 mL.
  - 표시 자리: 주입은 1 mL 단위라 남은 부피는 0.5 mL 단위가 될 수 있음 → 소수 첫째 자리까지, 정수면 소수점 없이(예: 3 mL, 2.5 mL).
  - 분자 모형 수 = 부피(mL) × 2 (모형 1개 = 0.5 mL). 반응할 때 수소 분자 2개 + 산소 분자 1개 → 물 분자 2개 짝으로 바뀜.

- 학생 조작
  1. 반응 고르기(반응마다 상자 수와 반응 상태를 따로 기억). 처음 상자 수는 교과서 그림 그대로(수증기 2·1, 염화 수소 1·1, 암모니아 1·3).
  2. 상자 [+]/[−]: 상자가 튀어나오며 생기거나 줄어들며 사라짐(0.25초 이징).
  3. [반응시키기]: 반응식 계수 묶음 단위로 반응할 수 있는 만큼 반응(아래 계산). 반응하는 상자의 분자가 원자로 흩어졌다가 생성물질 분자로 다시 붙으며 오른쪽 상자로 들어가는 애니메이션(약 2초). 남은 상자는 흐리게 오른쪽 끝으로 미끄러짐.
  4. **암모니아 적용하기**(활동+): 암모니아 생성을 처음 고르면 상자 수가 1·3으로 고정되고 [반응시키기] 대신 반응 후 자리에 **빈 상자 2개**와 그 아래 분자 카드 4장이 나옴 — (가) 질소 원자 1개 + 수소 원자 3개 분자, (나) 질소 원자 2개 + 수소 원자 6개 분자, (다) 질소 원자 1개 + 수소 원자 1개 분자, (라) 질소 분자 1개와 수소 분자 1개(따로 떨어짐). 카드 순서는 섞음. 카드를 끌어(또는 누른 뒤 상자를 눌러) 빈 상자에 넣음. 알맞은 카드면 두 상자가 모두 채워지고 반응 애니메이션 뒤 비 표가 채워지며 적용하기 완료 → 상자 +/−가 풀림. 알맞지 않으면 카드가 돌아가고 원자 수 기준의 까닭 한 줄("반응 전 질소 원자 2개·수소 원자 6개가 상자 2개에 똑같이 나뉘어 들어가야 해요", "(라)는 반응하지 않은 혼합 기체예요" 등). 정답 카드를 코드에서 '정답'이라는 이름으로 적지 않고 원자 수 계산(반응 전 원자 수 ÷ 생성물 상자 수)으로 판정.
- 계산 (화면에 나오는 수치와 공식·단위)
  - 반응식 계수 (a, b → c): 수증기 2H₂ + O₂ → 2H₂O (2, 1 → 2), 염화 수소 H₂ + Cl₂ → 2HCl (1, 1 → 2), 암모니아 N₂ + 3H₂ → 2NH₃ (1, 3 → 2).
  - 반응 횟수 n = min(⌊A ÷ a⌋, ⌊B ÷ b⌋) (A, B = 반응물질 상자 수). 반응한 상자: a·n, b·n, 생성 상자: c·n, 남은 상자: A − a·n, B − b·n.
  - 상자 1개 = 기체 1 부피 = 분자 모형 1개(대표). 부피 단위는 '부피'(교과서 표기).
  - 기체 부피 합: 반응 전 A + B, 반응 후 c·n + 남은 상자 수.
- 단순화한 부분 (교과서·실제와 다른 점)
  - 실제 물 합성 장치는 점화 순간 큰 압력으로 피스톤이 튕기고, 생긴 물이 아주 조금 수증기로 남음. 시뮬레이터는 튕김을 짧은 애니메이션으로만 보이고, 식은 뒤 물(액체)의 부피와 남은 수증기는 0으로 봄(교과서 실험 결과와 같게).
  - 반응은 항상 완전히 일어남(덜 반응하는 경우·측정 오차 없음). 눈금 읽기 값은 계산값 그대로.
  - 온도·압력은 일정하다고 보고 값을 보여 주지 않음(실온·대기압이라고만 적음).
  - 분자 모형 1개 = 0.5 mL(탭 ①), 상자 1개 = 1 부피 = 분자 1개(탭 ②)로 나타냄. 실제로는 같은 부피에 아주 많은 분자가 들어 있음(패널 작은 글로 안내).
  - 탭 ②는 분자 모형 단위로 반응하므로 계수 묶음이 다 차지 않으면 반응하지 않고 남음(예: 질소 1·수소 2 → 반응 없음, 알림 "수소 3 부피가 있어야 질소 1 부피와 모두 반응해요"). 실제 기체는 분자가 아주 많아 일부만 반응할 수 있으나, 상자 하나를 분자 하나로 대표한 모형이라 이렇게 정함.
  - 수증기 생성 반응의 탭 ②는 수증기가 기체로 있는 높은 온도를 가정(탭 ①과 조건이 다름을 칩 옆 글로 밝힘).
  - 점화기 안전 수칙(피스톤이 사람을 향하지 않게)은 점화 단추 옆 작은 글로만.
- 소리 (Web Audio API로 직접 합성, 첫 클릭 뒤 시작, 위 띠 [소리] 단추로 음소거)
  - 주입구 열기/닫기: 짧은 '딸깍'
  - 주사기로 넣기: 낮은 '쉬익'(잡음, 0.8초 서서히 줄어듦)
  - 점화기 누르기: '틱' 불꽃 소리, 반응이 일어나면 이어서 짧은 '펑'(저음 충격음), 물방울 맺힐 때 작은 '똑' 2~3번
  - 반응 없음: 낮은 '뚝' 한 번
  - 상자 +/−: 높낮이가 다른 '톡'
  - 반응시키기(탭 ②): 올라가는 짧은 음 3개
  - 적용하기 알맞은 카드: 맑은 '딩동', 알맞지 않은 카드: 낮은 '부웅'
- 구현 메모 (sim-builder, `sims/15-3-1-2-03/` = `index.html`·`style.css`·`main.js`)
  - 넣을 부피는 [−] 슬라이더 [+] (1~10 mL, 1 mL 간격, 키보드 화살표로도 조작). 관 전체 30 mL를 넘으면 거부.
  - 실제 주사기처럼 피스톤 막대 길이가 관 길이보다 길어야 해서 관 눈금은 1 mL = 12px(논리 좌표)로 그리고, 피스톤 아래 돋보기 칸(0.5 mL 작은 눈금, 34배 확대)에서 눈금을 읽게 함. 점화 직후 피스톤이 움직이는 동안 돋보기 글은 "움직이는 중…".
  - 장치 그림의 주입구 꼭지와 점화기도 직접 눌러 조작할 수 있음(단추와 같은 동작). 분자 모형 보기가 켜져 있으면 장치 위에 범례(수소 분자·산소 분자·물 분자 → 물방울)를 보임.
  - 기록표 '남은 기체' 칸은 지금 분자 모형 보기 상태를 따름(끄면 모든 줄 '?'). `labLog`에는 항상 실제 기체 이름을 보냄. 기록표는 최근 6줄만 보이고 번호는 반응 차례 그대로, `labLog`는 최대 30줄.
  - 탭 ②는 반응 전·후를 위아래 두 줄로 그림(가로·세로 화면 공통, 상자 최대 12개가 한 줄에 들어가게). 반응 뒤 '반응 전' 줄에는 흐린 빈 상자를 남겨 비교하게 함. 반응이 안 되는 조합(n = 0)도 [반응시키기]를 누르면 반응한 상태로 보고 모든 상자를 '남은 ○ 부피'로 옮김.
  - 적용하기 카드 라벨 (가)~(라)는 내용에 고정하고 놓이는 순서만 섞음(문항 6 보기와 라벨이 어긋나지 않게).
  - 비 표: 열 = 반응식 물질, 줄 = 계수비 / 분자 수(개) / 부피(부피) / 분자 수의 비 / 부피비. 반응시키기 전에는 모두 '–'.
  - `boxProduct`·`leftA`·`leftB`·`volAfter`는 반응시키기 전에는 `null`. `lastO2Before` 등 탭 ① 마지막 반응 키도 반응 전에는 `null`.
- 사용한 외부 도구: 없음(Canvas 2D·Web Audio API로 직접 그림·소리). 장치와 분자는 2D로 충분히 보이고 3D·물리 엔진은 저사양 크롬북 부담만 커서 쓰지 않음. 교과서 사진은 참고 이미지로 넣지 않고 위 글 설명만 보고 새로 그림.
