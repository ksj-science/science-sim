  - **월식**: 지구의 그림자 속으로 달이 들어가 달의 일부 또는 전체가 가려지는 현상.

- 사용한 외부 도구 (라이브러리·이미지 생성 도구 등, 쓴 까닭과 라이선스)
  - Three.js(MIT) + OrbitControls: 태양·지구·달 배치와 그림자 원뿔을 입체로 돌려 보게 하려고. `lib/vendor/`에 복사, importmap 사용.
  - 하늘 보기는 Canvas 2D로 직접 그림(원 겹침 계산이 단순해서 라이브러리 불필요). Chart.js 불필요.
  - 소리는 Web Audio API(직접 합성, 외부 파일 없음). 이미지 생성 도구는 쓰지 않음.
- 단순화한 부분 (교과서·실제와 다른 점)
  - 태양·지구·달의 크기와 거리는 모형 값(화면에 맞게 크게 줄임). '실제 크기 느낌' 모드도 정확한 비율이 아닌 "태양이 훨씬 크고 멀다"는 느낌만 줌. 화면에 크기·거리 숫자는 표시하지 않음.
  - 교과서 날짜 재생: **교과서의 진행 시간 처음과 끝(08:15, 13:35 / 22:27, 02:00)을 '가려지기 시작/완전히 벗어남' 순간으로 삼고**, 그 사이에서 달(또는 그림자)이 일정한 빠르기로 지나가며 진행 시간의 한가운데(10:55 / 00:13 무렵)에서 가장 많이 가려지도록 만든 모형. 실제 최대 시각·식분·개기 여부는 천문학습관 자료로 확인하도록 화면에 "모형: 실제 모양은 천문학습관에서 확인" 안내를 띄움.
  - 일식 모형: 하늘에서 태양과 달의 겉보기 크기를 같게 둠(교과서 "비슷한 크기"). 따라서 중심이 지나갈 때 잠깐 100 %가 됨. 금환 일식, 지역별 차이, 해의 고도 변화는 다루지 않음(하늘 보기에서 태양은 화면 가운데 고정, 관측 프로그램의 '태양 검색 후 가운데 두기'를 따름).
  - 월식 모형: 지구 그림자(본그림자) 반지름을 달 반지름의 2.6배로 둔 모형 값. 반그림자는 그리지 않음. 그림자 속 달은 완전히 사라지지 않고 붉고 어둡게 보이도록 그림(실제 관찰 모습에 가깝게, 수치는 없음).
  - 달의 이동 방향: 하늘 보기에서 달이 서(오른쪽)→동(왼쪽)으로 지나가게 함. 높낮이(궤도 기울기)는 '달의 높낮이' 모형 단위로만 표현하고 실제 각도는 표시하지 않음.
  - 지구 자전에 따른 하늘의 일주 운동은 빼고, 관측 대상을 화면 가운데 고정.
- 화면에 나오는 모든 수치와 공식·단위
  - 날짜·시각(년. 월. 일. 시:분) — 시작 시각 + 지난 시간. 1분 단위.
  - 지난 시간(분) = 현재 시각 − 교과서 진행 시작 시각(식 전이면 0, 식 끝 뒤면 전체 진행 시간). 단위 분.
  - 진행 비율 p = (현재 시각 − 시작 시각) ÷ (끝 시각 − 시작 시각), 0~1(화면에는 표시 안 함, 계산용).
  - 하늘 보기 중심 간격 d: 교과서 모드 d = (1 − 2p) × (R가림 + R대상) — 가림체가 서쪽(+)에서 동쪽(−)으로 지나감. 자유 배치 d = k × (달 위치 각도와 0°(또는 180°)의 차) 와 높낮이 h로 d = √(x² + h²) (k는 모형 상수).
  - 가린 비율(%) = 두 원의 겹친 넓이 ÷ 대상(태양 또는 달) 원 넓이 × 100. 겹친 넓이는 두 원 교차 넓이 공식 A = r₁²·acos((d²+r₁²−r₂²)/(2dr₁)) + r₂²·acos((d²+r₂²−r₁²)/(2dr₂)) − ½√((−d+r₁+r₂)(d+r₁−r₂)(d−r₁+r₂)(d+r₁+r₂)). 소수 첫째 자리까지 %로 표시.
  - 달의 위치 각도(°): 지구에서 본 태양 방향을 0°로, 공전 방향(위에서 보아 시계 반대 방향)으로 잰 각. 0~360°, 정수.
  - 달의 높낮이: −3~+3, 단위 없는 모형 값("모형 단위"라고 표시).
- SimBridge 상태 키
  - `mode` — 'solar' | 'lunar' | 'free', 단위 없음
  - `timeStr` — 현재 표시 시각 'YYYY-MM-DD HH:MM'
  - `elapsedMin` — 교과서 진행 시작부터 지난 시간, 분
  - `coverPct` — 현재 가린 비율, %
  - `maxCoverPct` — 이번 모드에서 학생이 본 가린 비율의 최댓값, %
  - `eclipseState` — 'none' | 'partialSolar' | 'totalSolar' | 'partialLunar' | 'totalLunar'
  - `firstCoveredSide` — 가려지기 시작할 때 대상의 어느 쪽(동/서)이 먼저 가려졌는지 'east' | 'west' | ''
  - `moonAngleDeg` — 달의 위치 각도, °
  - `moonHeight` — 달의 높낮이, 모형 단위
  - `orderSolar` / `orderLunar` — 학생이 놓은 순서 문자열(예: '태양-달-지구'), 미입력은 ''
  - `orderTried` — 순서 확인을 누른 횟수, 회
  - `viewedSolar` / `viewedLunar` — 해당 모드에서 식 시작부터 끝까지 시각을 넘겨 보았는지, true/false
  - `realScaleViewed` — '실제 크기 느낌'을 열어 보았는지, true/false

## 선생님 확인 메모
- 교과서 날짜 재생은 진행 시간의 처음·끝만 교과서 값이고, 가운데 최대 시각과 최대로 가려지는 정도는 모형입니다(화면에 안내). 수업에서 천문학습관의 실제 모습과 비교해 보게 하면 좋습니다.
- 월식 그림자 크기(달의 2.6배)는 모형 값입니다. 숫자는 화면에 나오지 않습니다.
- 문항 3은 '남쪽 하늘을 볼 때'를 전제로 합니다(하늘 보기에 동·서 표시).
