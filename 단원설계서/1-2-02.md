# 단원 설계서 — 1-2-02 변이와 생물의 다양성 (토끼의 종류가 다양해지는 과정)

- 학년·교과서: 중학교 과학1 (동아출판), 대단원 Ⅱ 생물의 구성과 다양성, 소단원 2. 생물의 다양성, 46~47쪽
- 성취기준: 변이의 의미를 이해하고, 변이와 환경의 관계를 통해 생물 다양성이 나타나는 과정을 설명할 수 있다.
- 차시 목표 (학생이 이 활동 후 할 수 있는 것):
  - 같은 종류의 생물 사이에서도 변이(털색 차이)가 있음을 말할 수 있다.
  - 서식지 환경에 따라 생존에 유리한 변이가 달라짐을 시뮬레이션 결과로 설명할 수 있다.
  - 서식지 분리 → 각 환경에서 유리한 변이를 가진 개체의 생존·번식 → 오랜 시간 누적 → 서로 다른 종류의 과정을 순서대로 말할 수 있다.
  - 변이가 다양하면 환경이 급변해도 멸종할 확률이 낮아짐을 설명할 수 있다.

## 교과서 요약 (이미지 대신 이 글을 기준으로 작업)
- 본문 요지
  - 생물은 다양한 환경에 적응하며 살아가므로 변이는 생존에 영향을 미칠 수 있다. 주변 환경과 몸 색깔이 비슷한 토끼는 천적의 눈에 잘 띄지 않아 살아남을 가능성이 높고, 살아남은 토끼는 자손을 남기며 자신의 특성을 자손에게 전달한다.
  - 같은 종류에 속하는 생물의 변이가 다양하면 환경이 급격하게 변하거나 전염병이 유행하더라도 그 변화에 적응할 수 있는 생물이 있어 멸종할 확률이 낮아진다.
  - 사는 곳의 환경이 달라지면 생존에 유리한 변이도 달라진다. 변이는 각각 다른 환경에 적응하는 과정에서 다양한 종류의 생물이 나타나는 주요 원인이 된다.
  - 다양한 변이를 가진 한 종류의 생물이 우연한 변화로 서식지가 나누어져 서로 다른 환경에 살게 되면, 각 서식지에서 생존에 유리한 변이를 가진 생물이 살아남고, 자손을 남기고 오랜 시간 변화가 누적되면 서로 다른 종류의 생물이 된다.
- 그림 Ⅱ-6 「토끼의 종류가 다양해지는 과정」 (5장면)
  1. 다양한 변이를 가진 한 종류의 토끼가 살고 있었다. — 초록 풀밭에 흰색·회색·갈색 토끼가 섞여 있음
  2. 서식지에 강이 생겨 두 무리로 나누어 살게 되었다. — 강 왼쪽은 초록 풀밭, 오른쪽은 모래·마른 땅(돌, 마른 풀). 양쪽 모두 여러 털색이 섞여 있음
  3. 각 서식지에서 눈에 잘 띄지 않는 토끼가 살아남았다. — 매가 흰 토끼를 잡아감. 탐구 질문 "각각의 무리에서 어떤 변이를 가진 토끼가 생존에 유리할지 생각해 보자."
  4. 살아남은 토끼는 자손을 남겼다. — 풀밭 쪽은 회색 토끼, 마른 땅 쪽은 갈색 토끼만 남음
  5. 매우 오랜 시간이 지나 강이 사라지고 두 무리가 만나게 되었지만, 이미 서로 다른 종류의 토끼가 되었다. — 풀밭에 회색 토끼와 갈색 토끼가 함께 있음
- 쓰는 용어: 변이, 생물 다양성, 서식지, 천적, 생존에 유리한 변이, 자손, 종류(종)
- 수치·조건: 교과서에 수치 없음 (그림만 제시)

## 시뮬레이터 (3차: 「토끼 무리의 대모험」, 사실적인 그림)
- 화면 구성 (1366×768, 스크롤 없음)
  - 머리줄: 제목, 5단계 진행 표시(변이 관찰 → 서식지 나뉨 → 천적과 생존 → 자손 남기기 → 다른 종류로), [도전 실험]·[처음부터]
  - 왼쪽 큰 장면(캔버스에 코드로 직접 그림, `sims/1-2-02/scene.js`): 구름이 흐르는 하늘, 완만한 초원 언덕, 짧고 촘촘한 풀. 강이 생기면 오른쪽은 주황빛 사막(모래 물결·자갈·모래 언덕)으로, 강은 하늘을 비춘 짙은 파랑에 물결 반짝임, 풀밭 쪽 물가에 덤불. 장면 위에 임무 카드, 아래에 조작줄(세대 수, 큰 버튼, 보통/빠르게)
  - 오른쪽: 무리 카드 2개(작은 토끼 아이콘으로 개체 수 그림 표시, 털색별 수, 세대별 털색 수 누적 영역 그래프), 「내 예측」 카드(예측과 결과 맞음/다름)
  - 토끼: 털을 한 올씩 그린 앉은 모습·뛰는 모습·정면 모습. 가끔 깡충깡충 돌아다니고, 방향을 바꿀 때는 정면 모습을 잠깐 거쳐 몸을 돌림. 숨 쉬듯 살짝 움직임
  - 매: 짙은 갈색, 금빛 뒷목, 날개 안쪽 흰 무늬, 손가락처럼 갈라진 첫째날개깃. 하늘에서 날개를 펴고 활공 → 날개를 접고 급강하 → 날개를 들어 올리며 발톱을 펴 낚아챔 → 토끼를 움켜쥐고 날갯짓하며 날아감. 땅에 그림자가 점점 커짐. 잡을 토끼가 많으면 여러 마리가 시간차를 두고 내려옴
  - 자손이 태어날 때 하트가 떠오르고, 새끼는 작게 태어나 자람
- 학생 조작 (장면별 임무)
  1. 다양한 변이: 풀밭의 토끼 24마리(흰 8·회 8·갈 8)를 눌러 세 가지 털색을 모두 찾음(말풍선 "회색 털 토끼 · 발견!") → '변이' 설명 → [다음 장면]
  2. 서식지 나뉨: 장면 가운데를 손가락·마우스로 **위에서 아래로 그어 강을 만듦**(그은 모양대로 강이 생김). 너무 짧거나 가장자리면 다시 안내. [자동으로 강 만들기]도 있음. 강 오른쪽은 사막으로 바뀌고, 강에 닿은 토끼는 자기 쪽으로 도망감
  3. 예측: "각 무리에서 어떤 털색의 토끼가 가장 많아질까?"를 풀밭·사막 무리마다 고름 → [매가 나타나요!]
  4. 천적과 생존·자손: [▶ 자동 진행]/[⏸ 멈춤], [1세대만], 속도 보통/빠르게. 10세대가 되면 결과 카드(가장 많아진 털색 vs 내 예측, ⭕/✖) → [세대 더 진행하기] 또는 [다음 장면]
  5. 다른 종류로: "아주 오랜 시간이 흘렀어요"(연도 넘어가는 장면) → 강이 마르고 두 무리가 섞임. 발밑 고리 색으로 출신 무리 표시(파랑: 풀밭, 주황: 사막). 토끼 두 마리를 차례로 눌러 짝을 지음 → 같은 무리 출신은 하트(자손을 남길 수 있음), 다른 무리 출신은 깨진 하트(자손을 남기지 못함). 둘 다 해 보면 정리 카드(변이 → 서식지 나뉨 → 생존 → 자손·누적 → 다른 종류)
  - 도전 실험 「변이가 없다면?」: 본 실험에서 10세대를 관찰하면 열림(정리 카드에서도 바로 가기). 흰 토끼 24마리로 같은 강·매를 겪게 하여 자동 진행 → 모두 사라지면 '멸종' 도장, 결과 카드에서 46쪽 "변이가 다양하면 멸종 확률이 낮아진다"와 연결
- 사용한 외부 도구
  - Chart.js 4.4.6 (MIT, `lib/vendor/chartjs-4.4.6/`) — 세대별 털색 수 누적 영역 그래프. 툴팁·부드러운 곡선 등 직접 그리는 것보다 낫기 때문
  - Jua 글꼴 5.3.0 (SIL OFL 1.1, `lib/vendor/jua-5.3.0/`, @fontsource/jua) — 제목·버튼용 둥근 한글 글꼴. 크롬북 기본 글꼴보다 수업 화면이 훨씬 친근해짐. 글자 범위별로 나뉜 woff2라 화면에 쓰인 글자 조각만 내려받음
  - 이미지 생성(Gamma·Canva)은 쓰지 않음: 토끼는 털색을 바꾸고 여러 자세로 움직여야 하고, 강 모양이 학생이 그은 대로 바뀌므로 캔버스에 코드로 그리는 편이 나음(Gamma는 크레딧 부족, Canva는 원본 크기 이미지를 받을 수 없기도 했음)
  - 선생님이 주신 사진(강·토끼·독수리·초원·사막)은 색감·모양을 맞추는 참고로만 보고 저장소에는 넣지 않음
- 단순화한 부분 (교과서·실제와 다른 점)
  - 변이는 털색 한 가지, 3가지 색으로만 나타냄. 털색은 부모와 같은 색으로 그대로 전달(돌연변이·섞임 없음)
  - 천적은 매 한 종류. 한 세대에 매에게 잡힐 확률은 배경색과 털색의 대비로 정함 — 교과서 4번 장면 결과에 맞춤
    - 풀밭: 흰색 0.7, 갈색 0.45, 회색 0.05 / 사막: 흰색 0.7, 회색 0.45, 갈색 0.05
  - 살아남은 토끼는 한 마리씩 같은 털색 자손을 남기고, 무리가 16마리를 넘으면 무작위로 16마리만 남음(먹이·공간 한계)
  - 강이 생길 때 토끼가 서 있던 쪽으로 무리가 나뉘되(우연), 털색마다 양쪽에 3마리 이상 있도록 강 가까이 있던 토끼를 옮겨 맞춤. 학생이 그은 강은 화면 가운데 부분(x 400~600)으로 제한
  - 수십 세대를 '세대' 단위로 압축. 실제 종 분화는 매우 오랜 시간이 걸림을 '시간이 흐르는 장면'으로 나타냄
  - "서로 다른 종류"는 출신 무리가 다르면 자손을 남기지 못하는 것으로 단순하게 보여 줌(유전적 차이를 계산하지 않음)
  - 결과에 우연이 들어가지만 경향은 항상 같게 나오도록 확률을 조정함. 2만 번 모의 실행 결과 10세대 뒤 각 무리에서 가장 많은 털색이 교과서 결과와 다를 확률은 약 0.02%, 무리가 사라질 확률 0%. 「변이가 없다면?」은 약 95%가 10세대 안에 모두 사라지고, 나머지도 몇 마리만 남음
- SimBridge 상태 키
  - `stage` — 현재 단계 (1~5)
  - `generation` — 「변이 있음」 실험에서 강이 생긴 뒤 지난 세대 수
  - `mode` — 지금 실험: `변이 있음` / `변이 없음`
  - `colorsFound` — 1단계에서 찾은 털색 수 (0~3)
  - `predictLeft`, `predictRight` — 학생 예측(풀밭·사막 무리에서 가장 많아질 털색, `흰색`/`회색`/`갈색`), 안 했으면 null
  - `left` — 「변이 있음」 실험의 풀밭 무리 털색별 수 `{white, gray, brown}`, 마리 (강이 생기기 전 null, 다른 실험 중에도 마지막 결과 유지)
  - `right` — 「변이 있음」 실험의 사막 무리 털색별 수 `{white, gray, brown}`, 마리
  - `merged` — 강이 사라져 두 무리가 만났는지 (true/false)
  - `crossPairTried` — 5단계에서 다른 무리 출신끼리 짝짓기를 해 봤는지 (true/false)
  - `noVariationTried` — 「변이가 없다면?」 실험을 끝까지(10세대 또는 모두 사라질 때까지) 해 봤는지 (true/false, 처음부터 해도 유지)
  - `noVariationSurvivors` — 그 실험에서 마지막에 남은 토끼 수, 마리

## 문항 (정답은 여기 적지 않음 → 학교 시트 `정답` 탭)
결과에 우연이 섞이므로 학생마다 수가 다를 수 있음 → 정확한 개체 수를 묻는 수치 문항은 두지 않고, 항상 같게 나오는 '경향'만 채점함.

| 번호 | 유형 | 문항 | 시뮬레이터 연결 |
| --- | --- | --- | --- |
| 1 | 객관식 | 처음 토끼 무리처럼 같은 종류의 생물 사이에서 나타나는 형질의 차이를 무엇이라고 하는가? (보기: 변이 / 적응 / 생태계 / 멸종) | 1단계 관찰 |
| 2 | 객관식 | 10세대가 지난 뒤 강 왼쪽(풀밭) 무리에서 가장 많아진 털색은? (흰색 / 회색 / 갈색) | `left` |
| 3 | 객관식 | 10세대가 지난 뒤 강 오른쪽(사막) 무리에서 가장 많아진 털색은? (흰색 / 회색 / 갈색) | `right` |
| 4 | 서술 | 두 서식지에서 살아남은 토끼의 털색이 서로 다른 까닭을 '환경', '눈에 띄지 않는'이라는 말을 넣어 쓰시오. | 키워드 채점(환경·눈에 띄 등) → 일부만 있으면 선생님 확인 |
| 5 | 단답 | 다음 과정을 일어난 순서대로 기호를 붙여 쓰시오. (예: ㄱㄴㄷㄹ) ㄱ. 각 서식지에서 생존에 유리한 변이를 가진 토끼가 살아남는다. ㄴ. 강이 생겨 서식지가 나누어진다. ㄷ. 오랜 시간 변화가 누적되어 서로 다른 종류가 된다. ㄹ. 살아남은 토끼가 자손을 남긴다. | 전체 과정 |
| 6 | 객관식 | 「변이가 없다면?」 실험 결과로 알 수 있는 것으로 옳은 것은? (보기: 털색이 모두 같으면 매에게 잡히지 않는다 / 변이가 다양하면 환경이 변해도 살아남는 생물이 있어 멸종할 확률이 낮아진다 / 변이가 없으면 자손을 더 많이 남긴다 / 서식지가 나뉘지 않으면 변이가 생기지 않는다) | `noVariationTried`, `noVariationSurvivors` |

- 채점: 1·2·3·6 객관식, 5 단답(공백 무시 정확 일치), 4 서술(키워드). 배점은 시트 `정답` 탭에서.
