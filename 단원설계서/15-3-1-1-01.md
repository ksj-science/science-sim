- 교육과정 범위 (넘지 않을 선)
  - 계수는 원자의 종류·개수를 세어 맞추는 방법(눈으로 맞추기)만. 미지수를 세우는 대수적 방법, 몰·질량 계산, 계수비로 질량비를 구하는 계산은 다루지 않음.
  - 물질의 상태 표시((s)·(l)·(g)·(aq)), 이온·이온식, 산화·환원 용어, 반응 조건(가열 기호 Δ 등)은 쓰지 않음.
  - 질량 보존 법칙·일정 성분비·기체 반응 법칙은 다음 중단원(2.) 내용이므로 이름을 내세우지 않음. 이 차시에서는 "원자는 새로 생기거나 없어지지 않으므로 화살표 양쪽 원자의 종류와 개수가 같아야 한다"(19쪽 본문)까지만.
- 차시 목표 (학생이 이 활동 후 할 수 있는 것)
  1. 화학 반응을 1단계(이름과 →, +) → 2단계(화학식) → 3단계(계수 맞추기) 순서로 화학 반응식으로 나타낼 수 있다.
  2. 화살표 양쪽의 원자 종류와 개수가 같아지도록 계수를 맞추되, 화학식(아래 첨자)은 바꾸지 않는 까닭을 말할 수 있다.
  3. 계수를 가장 간단한 정수비로 나타내고 1은 생략할 수 있다.
  4. 화학 반응식의 계수비가 분자(입자) 수의 비와 같음을 분자 모형으로 설명할 수 있다.

## 교과서 요약 (이미지 대신 이 글을 기준으로 작업)
- 16쪽 도입: 큰 숫자 '02'와 제목. 이 단원을 배우면 — 화학 반응을 화학 반응식으로 나타냄 / 계수의 비가 입자 수의 비를 나타냄을 설명. 핵심 역량: 과학적 사고력, 과학적 탐구 능력, 과학적 의사소통 능력.
  - 함께 시작하기 '화학 변화를 어떻게 나타낼까?': 김치볶음밥 만드는 과정을 1~6번 그림(재료 → 볶기 → 밥 넣기 → 양념 → 달걀 굽기 → '밥 + 달걀 + 깨 → 김치볶음밥')으로 나타낸 삽화. 화학 변화도 누구나 알기 쉽게 표현하는 방법이 있을지 이야기해 보자.
  - 본문: 화학 변화가 일어나 다른 물질로 변하는 과정 = **화학 반응**. 천연가스의 주성분인 메테인이 산소와 반응하여 연소하면 이산화 탄소와 물이 생성됨. 반응 전 물질(메테인, 산소) = **반응물질**, 반응으로 생성된 물질(이산화 탄소, 물) = **생성물질**.
  - 날개: 연소 = 물질이 산소와 빠르게 반응하면서 열과 빛을 내는 현상. '과학, 기술을 만나다' 천연가스 버스(대기 오염 물질 배출이 적음).
  - 그림 Ⅰ-5 '연료로 이용되는 메테인': 파란 불꽃이 둥글게 피어오르는 가스레인지 사진, 파란색 천연가스 버스 사진.
- 17쪽 본문: 글이나 모형보다 화학식을 쓰면 간단함. 반응물질과 생성물질의 화학식과 기호로 나타낸 것 = **화학 반응식**. 메테인 연소로 단계별 설명.
  - 날개: 화학식 = 원소 기호와 숫자로 물질을 나타낸 것(예: H₂O는 수소 원자 2개와 산소 원자 1개로 이루어진 물 분자). 계수 = 화학 반응식에서 화학식 앞의 숫자.
  - 1단계: 이름과 기호(→, +)로 — 메테인 + 산소 → 이산화 탄소 + 물. 말풍선: 반응물질은 화살표 왼쪽, 생성물질은 오른쪽, 여러 가지면 +로 연결.
  - 2단계: 화학식으로 — CH₄ + O₂ → CO₂ + H₂O. 분자 모형 그림: CH₄(가운데 큰 짙은 회색 C, 상하좌우에 작은 연회색 H 4개), O₂(빨간 O 2개가 붙음), CO₂(가운데 회색 C 양옆에 빨간 O, 일직선), H₂O(빨간 O 아래 양쪽으로 작은 H 2개, 굽은 모양).
  - 3단계: 화살표 양쪽 원자의 종류와 개수가 같도록 화학식 앞의 계수를 맞춤. 계수는 가장 간단한 정수비, 1은 생략 — CH₄ + 2O₂ → CO₂ + 2H₂O. 말풍선 요지: CH₄의 H가 4개라 H₂O 앞에 2, 그러면 오른쪽 O가 4개라 O₂ 앞에 2. 2O₂는 O₂ 모형 2개, 2H₂O는 H₂O 모형 2개. 양쪽 모두 C 1개, H 4개, O 4개.
  - 활동+ 추측하기: 1단계처럼 나타냈을 때 '→'와 '+'가 각각 무엇을 뜻하는지 써 보자.
  - 오해와 진실: 원자의 종류·개수를 맞출 때 화학식은 바꾸지 않고 계수를 바꾸는 까닭? — 계수를 붙이지 않고 H₂O, O₂의 화학식을 바꾸면 전혀 다른 물질의 화학식이 되기 때문.
- 18쪽 배움활동 '화학 반응을 화학 반응식으로 나타내기' (목표: 화학 반응을 화학 반응식으로 나타낼 수 있다. 역량: 사고력, 탐구 능력)
  - 조사하기 1: 붉은색 구리판을 공기 중에서 가열하면 검은색으로 변함. 사진 두 장 — 집게로 잡은 구리판이 가스 불꽃 위에서 주황색으로 달궈진 모습 → 화살표 → 검게 변한 구리판. 질문: 생성되는 검은색 물질은?
  - 조사하기 2: 이 반응의 반응물질과 생성물질의 화학식 조사.
  - 정리하기: 1단계(이름과 →, +) / 2단계(화학식) / 3단계(원자의 종류·개수가 같도록 계수 맞추기) 빈칸 표.
  - 더 나아가기: 마그네슘(Mg)과 염산(HCl)이 반응하면 수소(H₂) 기체가 발생하고 염화 마그네슘(MgCl₂)이 생성됨 → 화학 반응식으로. 사진: 염산이 든 비커에 마그네슘 리본을 꽂았고 리본 표면에서 기포가 올라옴.
- 19쪽 본문: 화학 반응식으로 나타내면 반응물질·생성물질을 한눈에 알 수 있음. 계수를 맞추는 까닭 = 반응 전후 원자는 새로 생기거나 없어지지 않으므로 화살표 양쪽 원자의 종류와 개수가 같아야 함. 계수로 물질의 입자 수 변화를 알 수 있음.
  - 그림 Ⅰ-6 '암모니아 생성 반응의 화학 반응식과 분자 모형': N₂ + 3H₂ → 2NH₃. 파란 N 2개가 붙은 N₂ 모형 1개, 연회색 H 2개가 붙은 H₂ 모형 3개, 파란 N 하나에 H 3개가 붙은 NH₃ 모형 2개. 아래 표 두 줄: 계수비 1 : 3 : 2 / 분자 수의 비 1 : 3 : 2. → 계수비는 분자 수의 비와 같다.
  - 활동+ 설명하기: 메테인 연소 반응식과 모형 — CH₄ 모형 + O₂ 모형 2개 → (빈칸: CO₂ 모형) + H₂O 모형 2개. 빈칸에 알맞은 모형을 그리고 까닭 설명.
  - 날개 '과학, 역사를 만나다': 하버의 암모니아 대량 생산과 과학자의 윤리.
  - 배운 내용 정리하기: (1) 화학식과 기호(→, +)로 화학 반응을 나타낸 식 = (   ) (2) 화학 반응식에서 계수비는 (   ) 수의 비와 같다.
  - 스스로 평가하기 3항목(반응식으로 나타내기 / 활동 참여 / 계수로 알 수 있는 것 설명).

- **선택: A.** 교과서가 화학 반응식을 1·2·3단계로 가르치고 배움활동 정리하기도 같은 3단계 표이므로, 그 단계를 화면 순서로 삼는 것이 차시 목표에 가장 직접 연결됨. 계수를 바꾸면 분자 모형이 통째로 늘어나는 장면(오개념 2), 아래 첨자를 바꿔 보는 체험(오해와 진실, 오개념 1), 반응 횟수를 바꿔 분자 수를 세는 표(그림 Ⅰ-6, 성취기준 둘째 줄)를 한 화면에 모을 수 있음. B의 '원자가 떨어져 다시 결합'은 A의 [반응시키기] 애니메이션으로 흡수, C는 넣지 않음.
- 겹침 검토: 같은 중단원(`15-3-1-1-`) 시뮬레이터 없음. 같은 대단원 `15-3-1-2-01`(일정 성분비, 자석 공으로 물·과산화 수소 분자 만들기)과는 학습 목표(질량비 vs 반응식·계수)와 조작(원자 끌어 조립 vs 계수 +/−)이 다름. 과산화 수소가 두 곳에 나오지만 여기서는 '아래 첨자를 바꾸면 다른 물질'의 예와 분해 반응식 하나로만 씀. 채팅 시뮬레이터는 열어 보지 않음.

- 학생 조작
  1. 반응 목록에서 반응 고르기(자유롭게 오감. 반응마다 단계·계수 상태를 따로 기억).
  2. 1단계: 이름 카드 끌기/누르기로 반응물질·생성물질 칸에 놓기. 잘못 놓으면 카드가 흔들리며 제자리로 돌아가고 까닭 한 줄("가열은 물질이 아니라서 반응식에 쓰지 않아요", "산화 구리(Ⅱ)는 반응으로 새로 생긴 물질이에요", "화살표 왼쪽에는 반응 전 물질을 써요").
  3. 2단계: 모형을 보고 화학식 고르기(물질마다 3개 중 1개. 예: 산소 — O / O₂ / O₃, 물 — H₂O / HO₂ / H₂O₂, 메테인 — CH₄ / C₄H / CH₂, 이산화 탄소 — CO₂ / CO / C₂O, 구리 — Cu / Cu₂ / C, 산화 구리(Ⅱ) — CuO / Cu₂O / CuO₂, 마그네슘 — Mg / Mn / Mg₂, 염산 — HCl / HCl₂ / H₂Cl, 염화 마그네슘 — MgCl₂ / MgCl / Mg₂Cl, 수소 — H₂ / H / H₃, 질소 — N₂ / N / NO, 암모니아 — NH₃ / N₃H / NH₄, 과산화 수소 — H₂O₂ / H₂O / HO). 틀리면 "모형에서 원자 수를 다시 세어 봐요"와 모형의 원자를 하나씩 반짝임. 단추 순서는 반응마다 섞음.
  4. 3단계: 계수 +/−(1~6). 바뀔 때 분자 모형이 하나 튀어나오며 생기거나(0.25초 이징) 줄어들며 사라짐. 원자 수 막대가 부드럽게 늘고 줄어듦.
  5. **아래 첨자 바꿔 보기**: 3단계 화학식 카드의 원소 기호를 누르면 작은 창 "이 원자 수를 바꿔 볼까요? [−] n [+] (1~4)". 바꾸면 그대로 적용되어 모형·원자 수가 바뀌고, 카드 테두리가 빨간 빗금, 이름표가 "다른 물질!"(아래 표에 있는 화학식이면 그 이름도: H₂O₂ 과산화 수소, H₂O 물, O₃ 오존, CO 일산화 탄소, 그 밖은 "이 반응에 나오지 않는 물질"). 알림 "화학식을 바꾸면 전혀 다른 물질이 돼요. 계수만 바꿔야 해요" + [화학식 되돌리기]. 바뀐 상태에서는 원자 수가 맞아도 완성 처리하지 않음.
  6. [반응시키기]: 계수가 맞든 틀리든 실행 가능(애니메이션 약 2.4초, 아래 '반응 애니메이션'). 끝나면 모형 상자 오른쪽에 생성물질 모형, 표 채움. [반응 전으로]로 되돌림.
  7. 반응 횟수 [1]~[4]: 반응식대로 몇 번 반응하는지(반응물질·생성물질 모형이 계수 × 횟수만큼). 표의 분자 수·분자 수의 비가 갱신됨.
  8. 공통: 일시정지/재생(애니메이션 멈춤), 초기화(지금 반응을 1단계 처음으로, 다른 반응의 완성 기록은 유지). 완성 기록까지 지우는 [모두 처음부터]는 초기화 단추를 길게 누르거나 확인창에서.
  9. [도움말](오른쪽 열 맨 아래 작은 단추): 3단계 힌트 한 줄씩 — "한 물질에만 들어 있는 원자부터 맞춰 봐요", "O₂처럼 원소 하나로 된 물질은 마지막에 맞추면 쉬워요"(계수 값은 알려 주지 않음).
- 판정과 알림 (오른쪽 '완성된 반응식' 아래 한 줄)
  - 원소 하나라도 양쪽 원자 수가 다르면: "○ 원자 수가 달라요(반응 전 a개, 반응 후 b개)" — 가장 위 원소 하나만.
  - 모두 같지만 계수의 최대공약수 g > 1: "원자 수는 같아요. 그런데 모든 계수를 g로 나눌 수 있어요 — 가장 간단한 정수비로 나타내요". 반응 횟수 단추는 꺼진 채.
  - 모두 같고 g = 1, 아래 첨자를 바꾸지 않음: "완성! 화살표 양쪽 원자의 종류와 개수가 같아요" → 반응 목록 체크, 단계 3칸 모두 체크, 밝은 효과음, 반응 횟수 단추 켜짐. 완성된 반응식을 목록 카드에 기록.

- 반응 애니메이션 (Canvas 2D, requestAnimationFrame)
  - ① 0~0.6초: 반응물질 분자의 원자들이 결합을 풀고 살짝 흩어짐(결합선이 끊기는 효과). ② 0.6~1.8초: 각 원자가 반응 후 자리의 같은 원소 빈자리로 곡선 경로를 따라 이동(easeInOutCubic, 원자마다 0~0.2초 시차). 원자의 색·크기·기호는 그대로. ③ 1.8~2.4초: 생성물질 분자로 붙으며 살짝 튕김. 화살표 안에 빛이 왼쪽→오른쪽으로 흐름.
  - 계수가 안 맞으면: 생성물질 자리 수는 지금 계수대로 만들고, 들어갈 원자가 없는 자리는 점선 빈 원 + "?"로, 갈 곳이 없는 원자는 모형 상자 아래 '남은 원자' 칸으로 가서 깜박임. 알림 "원자는 반응 중에 새로 생기거나 없어지지 않아요. 계수를 다시 맞춰 봐요".
  - 반응 횟수 n이면 n세트를 한꺼번에 반응(분자 모형 수 = 계수 × n, 한 칸 최대 12개, 넘지 않음 — 완성 상태의 계수는 이 6개 반응에서 3 이하).
- 소리 (`lib/sound.js` 위 Web Audio. 첫 클릭 뒤 시작, 음소거 상태 기억)
  - 카드 집기 '톡', 맞게 놓기 '착', 잘못 놓기 낮은 '뚱'(작게), 화학식 맞음 '딩', 틀림 짧은 '부'.
  - 계수 + : 올라가는 '뽁', − : 내려가는 '뽁'. 원소 한 줄이 균형이 되는 순간 맑은 '팅'(원소마다 음 높이 다르게).
  - 아래 첨자 바꾸기: 흔들리는 경고음 '우웅'. 되돌리기: 되감기 '슉'.
  - 반응시키기: 결합이 풀릴 때 가벼운 '톡톡'(원자 수만큼, 최대 8번), 이동할 때 '쉬익', 붙을 때 '착착'. 남은 원자 있음: 둔한 '퉁' 두 번.
  - 완성: 밝은 3음 화음. 단계 넘어감 2음. 초기화 내려가는 2음.
- 단순화한 부분 (교과서·실제와 다른 점)
  - 구리·산화 구리(Ⅱ)·마그네슘·염화 마그네슘은 실제로는 분자가 아니라 많은 입자가 규칙적으로 모인 물질이고, 염산은 염화 수소가 물에 녹은 수용액임. 시뮬레이터는 화학식 한 단위를 공 묶음 하나(입자)로 그려 개수를 셈. 이런 반응의 표는 '입자 수'로 표시.
  - 분자 모형의 크기·결합 각도는 모양을 알아보기 위한 근삿값(H₂O 굽은 모양, NH₃ 세 다리 모양 정도). 실제 원자 크기 비율이 아님.
  - 반응 애니메이션은 원자가 모두 떨어졌다가 다시 붙는 모습으로 그린 개념 모형이며, 실제 반응이 일어나는 과정(단계·속도·에너지)은 나타내지 않음. 가열·불꽃·기포 같은 반응 조건과 상태 표시는 그리지 않음.
  - '물의 생성', '과산화 수소의 분해'는 이 쪽에 나오지 않지만 원리 연습을 위해 넣음(물·과산화 수소의 화학식은 앞 학년·같은 대단원에서 쓰는 것).
  - 계수 범위 1~6, 반응 횟수 1~4, 아래 첨자 바꿔 보기 범위 1~4로 제한.
- 화면에 나오는 모든 수치와 공식·단위
  - 계수 c (정수 1~6, 단위 없음).
  - 원소 X의 원자 수(반응 전) = Σ(반응물질 i) cᵢ × (화학식 i 속 X의 수) × n, 반응 후도 같은 방법(개). n = 반응 횟수(3단계 계수 맞추기 중에는 1).
  - 분자(입자) 수 합계 = Σ cᵢ × n (개), 반응 전·후 따로.
  - 표: 계수비 = c₁ : c₂ : …(반응식 그대로), 분자 수 = cᵢ × n(개), 분자 수의 비 = 분자 수 ÷ 최대공약수(정수비).
  - 가장 간단한 정수비 판정: 모든 계수의 최대공약수 g, g = 1이면 가장 간단함.
- 화면 글자 표기: 아래 첨자는 `<sub>` 또는 유니코드 아래 숫자(₂₃₄)로, 반응식은 "CH₄ + 2O₂ → CO₂ + 2H₂O"처럼 + 양옆 띄어 씀. 계수와 화학식은 붙여 씀.
- SimBridge 상태 키 (바뀔 때 0.15초 단위로 모아 보냄)
  - `reaction` — 지금 반응 'methane' | 'copper' | 'mg_hcl' | 'ammonia' | 'water' | 'h2o2'
  - `step` — 지금 단계 1 | 2 | 3
  - `coefs` — 지금 계수, 반응식 순서대로 쉼표 구분(예: '1,2,1,2')
  - `equation` — 지금 계수로 쓴 반응식 글자(1 생략, 유니코드 아래 숫자)
  - `balanced` — 모든 원소의 원자 수가 양쪽 같은지 (true/false, 아래 첨자를 바꾼 상태면 바꾼 화학식 기준)
  - `simplest` — 계수의 최대공약수가 1인지
  - `formulaChanged` — 지금 아래 첨자를 바꾼 상태인지, `subscriptTried` — 한 번이라도 바꿔 봤는지, `changedFormula` — 마지막으로 바꿔 만든 화학식(예: 'H₂O₂')
  - `atomsLeft` / `atomsRight` — 원소별 원자 수, 예: 'C:1,H:4,O:4'
  - `moleculesLeft` / `moleculesRight` — 분자(입자) 수 합계, 개
  - `runs` — [반응시키기] 누른 횟수, `unbalancedRunTried` — 계수가 안 맞은 채 반응시켜 본 적이 있는지
  - `runCount` — 반응 횟수 n
  - `lastRun` — 마지막 반응 실행의 물질별 분자 수, 예: 'N₂:3,H₂:9,NH₃:6'
  - `solved` — 완성한 반응 목록, 쉼표 구분(예: 'methane,copper')
  - `solvedEquations` — 완성한 반응식, ' / ' 구분
  - `step1Mistakes` / `step2Mistakes` — 1·2단계에서 틀린 횟수(지금 반응 기준)
  - `hintsUsed` — 도움말을 본 횟수
- 성능·잠금
  - 애니메이션·계수 변화 이징이 있을 때만 requestAnimationFrame, 멈춰 있으면 그리지 않음. 품질 '낮음': 화소 비율 1, 공 그림자·광택 그라데이션 생략.
  - 웹앱 잠금(`.sim-locked` 또는 lock 메시지): 모든 조작 비활성, 소리 끔.
