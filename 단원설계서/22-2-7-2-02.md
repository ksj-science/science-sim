# 단원 설계서 — 22-2-7-2-02 달의 위상 변화

> 단원 ID `22-2-7-2-02` = 2022 개정 과학2, 대단원 7, 중단원 2, 2번째 시뮬레이터. 개정연도 판단 근거: 교과서에 개정연도 표기는 없으나, 2026학년도 2학년 교과서(동아출판 중학 과학2)이고 쪽 아래 표기가 'Ⅶ. 태양계'(234쪽)·'2. 지구와 달'(235쪽)로 동아출판 2022 개정 과학2 차례와 맞음 → 2022 개정.

- 학년·교과서: 중학교 과학2 (동아출판), 대단원 Ⅶ 태양계, 중단원 2 지구와 달, 소단원 03 달의 위상 변화, 234~235쪽
- 성취기준: [9과13-03] 지구와 달의 운동으로 달의 위상 변화(와 일식·월식)를 설명할 수 있다. — 이 차시는 달의 위상 변화만 다룸(일식·월식은 다음 차시). 성취기준 번호·문구는 교과서에 적혀 있지 않아 2022 개정 과학과 교육과정에서 해당 내용으로 맞춤(선생님 확인 필요).
- 차시 목표 (학생이 이 활동 후 할 수 있는 것):
  1. 달은 스스로 빛을 내지 않고, 태양을 향한 절반이 늘 밝다는 것을 모형으로 확인한다.
  2. 태양·지구·달의 위치 관계에 따라 지구에서 보이는 밝은 부분이 달라짐을 설명한다.
  3. (가)~(아) 8위치의 위상을 삭 → 초승달 → 상현달 → 보름달(망) → 하현달 → 그믐달 → 삭 순서로 짝지을 수 있다.
  4. 우리나라에서 상현달은 오른쪽이, 하현달은 왼쪽이 둥근 반달로 보임을 안다.

## 교과서 요약 (이미지 대신 이 글을 기준으로 작업)
- 도입: "달 하면 떠오르는 모양 그리기". 달을 매일 같은 시각에 보면 모양이 조금씩 바뀌고 위치도 전날보다 서쪽에서 동쪽으로 조금씩 옮겨 감(이 차시에서는 모양 변화만 다룸).
- 실험·탐구 장면 (탐구 '달의 위상 변화 관찰하기', 조작형):
  - 준비물: 스타이로폼 공(지름 10 cm), 막대, LED 손전등, 카메라, 달의 위상 붙임딱지(279쪽).
  - 과정: ① 한 사람은 막대에 꽂은 공(달)을 들고, 다른 사람은 떨어진 곳에서 카메라(지구의 관측자)를 든다. ② 교실을 어둡게 하고 한쪽에서 전등(태양)을 켠다. ③ 공을 든 사람이 카메라 든 사람 둘레를 원을 그리며 천천히 돌고, 카메라 든 사람은 공을 향한 채 제자리에서 돌며 공을 찍는다.
  - 그림: 오른쪽에 받침대 위 전등, 가운데 카메라 든 학생, 그 둘레 바닥에 타원 궤도와 빨간 점 8개. 전등 쪽(오른쪽)이 (가), 시계 반대 방향으로 (나)(다)(라)(마)(바)(사)(아). 궤도에 시계 반대 방향 화살표.
  - 안전: 전등 빛을 직접 보지 않기, 밝기를 조절해 눈부시지 않게.
- 정리하기:
  1. (가)~(아)에서 찍은 사진과 같은 위상의 붙임딱지 붙이기. 그림: 검은 우주 배경, 오른쪽 끝에 태양, 가운데 지구(태양 쪽 절반이 밝음), 지구 둘레 8위치의 달(각각 태양 쪽 절반이 밝음), 빨간 화살표로 시계 반대 방향 공전. 위치 이름: (가) 삭, (나) 초승달, (다) 상현달, (라) 이름 없음, (마) 망(보름달), (바) 이름 없음, (사) 하현달, (아) 그믐달.
     - (가) 삭: 달이 태양과 같은 방향 → 밝은 면이 보이지 않음.
     - (다) 상현달: 달이 태양과 직각 방향 → 오른쪽이 둥근 반달.
     - (마) 망: 달이 태양과 반대 방향 → 밝은 면이 모두 보임.
     - (사) 하현달: 직각 방향 → 왼쪽이 둥근 반달.
  2. 달의 밝게 보이는 부분이 달라지는 까닭 토의.
- 본문 요약: 달은 스스로 빛을 내지 못하지만 태양을 향한 절반은 항상 햇빛을 받아 밝다. 달은 지구 둘레를 약 한 달에 한 바퀴 시계 반대 방향으로 공전하고, 태양·달·지구의 위치가 달라지면서 보이는 모양이 달라진다 → **달의 위상 변화**.
- 스스로 확인하기: 위상 순서 빈칸(삭 → 초승달 → ( ) → 보름달 → 하현달 → ( ) → 삭), 우리나라 상현달은 (왼쪽, 오른쪽)이 둥근 반달.
- 과학 가치·태도: 망·삭인 날의 명절 찾아보기(보름달 사진).
- 쓰는 용어 (교과서 표기): 달의 위상, 달의 위상 변화, 삭, 초승달, 상현달, 망(보름달), 하현달, 그믐달, 공전, 시계 반대 방향, 햇빛, 반달.
- 수치·조건 (교과서에 나온 값): 공 지름 10 cm, 공전 주기 '약 한 달', 위치 8곳, 상현·하현은 태양과 직각 방향, 삭은 같은 방향, 망은 반대 방향.

## 시뮬레이터
- 화면 구성
  - 1366×768 (가로)
    - 위 머리줄(높이 약 48 px): 제목 "달의 위상 변화" + 단원 ID 표시, 오른쪽 끝에 음소거·초기화 버튼.
    - 왼쪽 큰 영역(약 860×640): **우주 시점** 3D 장면. 위(북극 쪽)에서 비스듬히 내려다봄. 오른쪽 끝에 태양(빛나는 구, 화면 밖에서 평행광), 가운데 지구(태양 쪽 절반 밝음, 북극이 위), 지구 둘레 원 궤도에 달과 8개 위치 표시점 (가)~(아)((가)가 태양 쪽, 시계 반대 방향 순). 궤도 위 시계 반대 방향 화살표. 마우스/터치로 카메라 회전·확대, '위에서 보기' 단추로 정면 위 시점 복귀.
    - 오른쪽 패널(약 480 폭), 위에서 아래로:
      1. **지구에서 본 달** 둥근 창(약 260×260): 지구 중심에서 달을 바라본 모습(북쪽이 위). 배경은 밤하늘.
      2. 수치판: 위치 이름, 공전 각도, 삭 후 지난 날수, 지구에서 밝게 보이는 비율, 햇빛 받는 부분(항상 50 %).
      3. 보기 설정 켜기/끄기: '햇빛 받는 반쪽'(노란 테두리), '지구에서 보이는 반쪽'(파란 테두리), '지구 그림자'.
      4. 붙임딱지 판: 8칸 (가)~(아) 빈칸 + 아래 카드 10장(위상 8장 + 좌우 뒤집힌 함정 카드 2장).
    - 아래 줄(왼쪽 영역 밑): 재생/일시정지, 공전 빠르기 슬라이더, 8위치 단추 (가)~(아), **위상 띠**(지나온 위상이 왼쪽부터 쌓이는 가로 띠).
  - 768×1024 (세로): 머리줄 → 우주 시점 3D(전체 폭, 높이 약 440) → 한 줄에 [지구에서 본 달 창 220×220 | 수치판] → 위치 단추·재생·슬라이더 → 붙임딱지 판(카드는 2줄로 접음) → 보기 설정. 스크롤 없이 들어가도록 카드 크기를 줄임.
- 학생 조작
  1. 시작 예측: "달 모양이 바뀌는 까닭은?" 두 가지 중 고르기(지구 그림자가 가려서 / 햇빛 받는 쪽과 우리가 보는 쪽이 달라서). 고른 뒤 바로 시작(정답 표시 없음, 활동 끝에 다시 물음).
  2. 달을 궤도 위에서 끌어 옮기기(손을 놓으면 가까운 표시점에서 3° 안이면 붙음), 또는 (가)~(아) 단추로 이동(이징 애니메이션).
  3. 재생 단추로 시계 반대 방향 공전(빠르기 슬라이더 0.5~4배, 1배 = 한 바퀴 약 24초).
  4. 보기 설정 3가지 켜고 끄기.
  5. 붙임딱지: 카드를 칸으로 끌어 놓기(터치·마우스). 맞으면 고정, 틀리면 원래 자리로 돌아가며 그 위치 달의 실제 모습을 잠깐 나란히 보여 줌.
  6. 과제 단추 "보름달 만들기", "상현달 만들기": 달을 옮겨 해당 위상을 만들면 완료 표시.

  - 8칸 모두 완성: 짧은 상승 아르페지오.
  - 보기 설정 켜기/끄기: 작은 토글 클릭.
- 사용한 외부 도구 (라이브러리·이미지 생성 도구 등, 쓴 까닭과 라이선스)
  - Three.js(MIT): 태양-지구-달의 입체 위치 관계와 '반쪽이 밝은 구'를 실제 조명으로 보여 주기 위해. 보조 카메라를 지구 중심에 두어 '지구에서 본 달'을 같은 장면에서 렌더링하면 위상 모양이 계산이 아니라 조명 결과로 나와 정확함. `lib/vendor/three-<버전>/`에 LICENSE와 함께 두고 importmap으로 불러옴.
  - 이미지 생성 도구는 쓰지 않음(지구·달 표면은 절차적 텍스처 또는 단색 PBR 재질로 충분). 쓰게 되면 도구 이름을 여기에 추가.
- 단순화한 부분 (교과서·실제와 다른 점)
  - 크기·거리 비율은 실제와 다름(태양은 화면 밖 평행광, 지구-달 거리 축소). 화면에 "크기와 거리는 실제 비율이 아님" 표시.
  - 달의 공전 궤도면을 지구 공전 궤도면과 같은 평면으로 둠(실제는 약 5° 기울어짐). 그래서 '지구 그림자' 설정을 켜면 (마) 근처에서 그림자가 달에 닿을 수 있는데, 이 차시에서는 위상만 다루므로 **달에 그림자가 드리우는 효과는 그리지 않고**, 그림자는 반투명 원뿔로 위치만 보여 줌. 이 사실을 그림자 설정 옆 작은 글씨("실제로는 달 궤도가 조금 기울어 있어 보름달 때 대부분 그림자를 비껴감")로 알림. 일식·월식은 다루지 않음.
  - 공전하는 동안 지구의 공전(태양 둘레 이동)은 멈춰 있다고 봄. 날수는 삭에서 다음 삭까지 약 29.5일로 환산(교과서 '약 한 달').
  - 지구 자전과 하늘에서 달이 뜨고 지는 시각, '같은 시각에 서→동으로 이동'은 이 차시에서 다루지 않음.
  - '지구에서 본 달'은 북반구(우리나라) 관측자 기준, 북쪽이 위. 남반구 모습은 다루지 않음.
  - (라)·(바)는 교과서에 이름이 없으므로 화면에서도 위치 기호만 보여 주고 이름 칸은 "(이름 없음)"으로 둠.
  - 달의 자전(같은 면이 지구를 향함)은 표면 무늬로 자연스럽게 반영하되 따로 설명하지 않음.
- 화면에 나오는 모든 수치와 공식·단위
  - 공전 각도 θ (°): 지구에서 본 태양 방향을 0°로, 시계 반대 방향(북극 쪽에서 볼 때)으로 잰 달의 각도. 0 ≤ θ < 360, 정수로 표시. 8위치: (가) 0°, (나) 45°, (다) 90°, (라) 135°, (마) 180°, (바) 225°, (사) 270°, (아) 315°.
  - 삭 후 지난 날수 (일): d = θ / 360 × 29.5, 소수 첫째 자리까지 "약 ○.○일".
  - 지구에서 밝게 보이는 비율 (%): f = (1 − cos θ) / 2 × 100, 정수 %로 표시. (가) 0 %, (다)·(사) 50 %, (마) 100 %.
  - 햇빛 받는 부분 (%): 항상 50 % (달 표면 전체 중 태양을 향한 절반).
  - 위치 이름: θ가 표시점 ±22.5° 안이면 그 위치 기호와 이름(삭, 초승달, 상현달, (라), 망(보름달), (바), 하현달, 그믐달).
  - 공전 빠르기 (배): 0.5~4, 1배 = 한 바퀴 24초(화면 시간).
- SimBridge 상태 키
  - `angleDeg` — 현재 공전 각도 θ, ° (정수)
  - `position` — 가장 가까운 위치 기호 '가'~'아'
  - `phaseName` — 현재 위상 이름(삭, 초승달, 상현달, 망(보름달), 하현달, 그믐달, 또는 빈 문자열)
  - `litPercent` — 지구에서 밝게 보이는 비율, % (정수)
  - `daysAfterNew` — 삭 후 지난 날수, 일 (소수 첫째 자리)
  - `visited` — 지금까지 달을 놓아 본 위치 기호 목록(예: "가,나,다"), 8개 모두면 탐색 완료
  - `cardsPlaced` — 붙임딱지를 맞게 붙인 칸 수, 0~8
  - `cardMistakes` — 붙임딱지를 잘못 놓은 횟수, 회
  - `mirrorMistake` — 좌우 뒤집힌 함정 카드를 상현·하현 칸에 놓은 적이 있는지, true/false
  - `prediction` — 시작 예측 선택('그림자' 또는 '방향'), 끝 예측은 `predictionAfter`
  - `taskFull` / `taskFirstQuarter` — '보름달 만들기'·'상현달 만들기' 완료 여부, true/false
  - `showLitHalf` / `showSeenHalf` / `showShadow` — 보기 설정 켜짐 여부, true/false
