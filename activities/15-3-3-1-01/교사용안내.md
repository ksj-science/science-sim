## 수업 흐름 (45분)
| 시간 | 내용 |
| --- | --- |
| 도입 5분 | 활동지 1번 무빙워크(예측 + 까닭). 빠르기가 일정하다는 말을 학생 말로 풀게 하고 '등속 운동' 소개 |
| 활동 25분 | 활동지 2~3번 [교과서 실험]: 1초씩 ▶ → 확대경 → 표 1·표 2 (약 10분) / 4번 그래프 점 찍기·그래프 확인 (약 7분) / 5번 기울기 보기·넓이 보기 (약 4분) / 6번 [속력 바꾸기] (약 4분, 남는 시간에) |
| 정리 10분 | 정리하기 4가지 확인(이동 거리 변화, 속력 변화, 기울기, 넓이), 6번 그림 이해하기, 7번 오개념 확인 나누기 |

6번은 시간이 부족하면 숙제로 돌립니다. 웹앱 확인문제는 활동 뒤 또는 남는 시간에 풀게 합니다.

## 흔한 오개념과 짚을 장면
| 오개념 | 짚는 장면 |
| --- | --- |
| 올라가는 선 = 속력이 빨라짐 | 4번에서 두 그래프를 나란히 놓고 비교. 달리는 동안 '지금 시각' 점선이 두 그래프에서 함께 움직임. 5번 [기울기 보기]에서 구간을 바꿔도 같은 값. 6번 겹친 선(빠를수록 '더 높음'이 아니라 '더 가파름') |
| 그래프 모양 = 실제 경로(비탈, 멈춤) | 장면 속 자동차는 늘 수평 자 위. 그래프의 축 이름(세로축·가로축)부터 읽게 함 |
| 구간 속력을 1초, 2초 같은 정수 시각에 찍음 | 3번·4번. 정수 시각에 찍으면 주황색으로 표시됨. 구간 가운데 안내와 교과서 활동 길잡이 연결 |
| 구간 이동 거리에 누적 거리를 씀 | 3번 표 2. "나중 위치 − 처음 위치"를 말로 확인 |
| 넓이·높이·기울기 혼동 | 5번 [넓이 보기]의 식을 읽고 자 위 거리와 비교 |

## 예상 어려움과 도움 발문
- 확대경 눈금 읽기가 어렵다: "자동차 어느 쪽 끝을 재고 있나요? 파란 기준선과 눈금이 만나는 곳은?"
- 표 확인이 계속 주황색: "처음 위치에서 잰 거리인가요, 그 구간에서만 움직인 거리인가요?"
- 속력 점을 어디에 찍을지 모름: "0초~1초의 속력을 대표하는 시각은 언제쯤일까요?"
- 기울기 보기가 안 열림: "두 그래프를 모두 [그래프 확인]으로 맞게 그렸나요?"
- 6번 '더 빠르다 = 더 높다' 반응: "같은 1초에서 두 선의 높이 차이가 아니라 올라가는 정도를 비교해 볼까요?"
