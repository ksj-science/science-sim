**학습 목표**
- 일식과 월식이 일어날 때 태양·지구·달이 일직선상에서 어떤 순서로 놓이는지 말할 수 있다.
- 일식과 월식에서 무엇이 무엇을 가리는지, 어느 쪽부터 가려지는지 설명할 수 있다.

> 시뮬레이터 화면은 두 칸이에요. 왼쪽 **우주에서 본 배치**는 우주 밖에서 본 모습, 오른쪽 위 **하늘 보기**는 땅 위에서 남쪽을 향해 서서 본 모습이에요. 하늘 보기에서는 왼쪽이 동쪽, 오른쪽이 서쪽이에요.
> 크기·거리는 모형이에요. 실제 모습은 천체 관측 프로그램(천문학습관)으로 확인할 수 있어요.

## 3. 2035년 9월 2일 일식을 관찰하자 【예측 → 조작 → 관찰】

**예측** 태양은 동쪽과 서쪽 중 어느 쪽부터 가려질까요? ( 동쪽 / 서쪽 )

**할 일**
1. 위쪽 탭에서 **[일식 2035. 9. 2.]** 를 누른다.
2. 시각 08:00에서 **[+1분]** 을 눌러 1분씩 넘긴다. 슬라이더의 빨간 눈금 **'교과서 진행 시작 08:15'** 근처에서 하늘 보기를 잘 본다.
3. 그 뒤에는 **[+10분]** 이나 **[재생]**(재생 빠르기 1분/초·5분/초·15분/초)으로 **'진행 끝 13:35'** 를 지날 때까지 본다.

**관찰** 읽음값(가린 비율·지난 시간·식 상태·가리는 것)을 보고 채워요.

| 처음 가려지기 시작할 때 | | | | |
| 가린 비율이 가장 클 때 | | | | |

- 교과서 진행 시간(08:15~13:35)은 모두 몇 분일까요? '지난 시간'으로 확인: ______ 분
- 하늘 보기에서 태양 모양이 바뀌는 모습을 순서대로 그려 보세요.

## 6. 달은 매달 태양 쪽으로 오는데, 일식은 매달 일어날까? 【예측 → 조작 → 관찰 → 설명】

**예측** 달이 지구 둘레를 돌다가 태양 쪽(0°)에 올 때마다 일식이 일어날까요? ( 그렇다 / 아니다 / 잘 모르겠다 )

**할 일**
1. 위쪽 탭에서 **[자유 배치]** 를 누른다.
2. **[0° (태양 쪽)]** 을 누르고, **[높낮이 0]** 을 누른다.
3. **'달의 높낮이'** 슬라이더(또는 **[아래]**·**[위]** 단추)로 높낮이를 바꾸며 읽음값을 적는다.
4. **[180° (반대쪽)]** 을 누르고 같은 방법으로 해 본다.

**관찰**

| 달의 위치 각도 | 달의 높낮이 | 가린 비율 (%) | 식 상태 |
| --- | --- | --- | --- |
| 0° | 0.0 | | |
| 0° | 1.0 | | |
| 0° | 2.0 | | |
| 180° | 0.0 | | |
| 180° | 2.0 | | |
| 180° | 3.0 | | |

- 높낮이를 바꾸면 우주에서 본 배치에 무엇이 나타나나요? 달은 태양-지구를 잇는 점선과 비교해 어디에 있나요?
