## 1단계 ① 물결 연못

### 문항 1. 오리는 어떻게 될까? [예측 → 조작 → 관찰]

**예측.** 잔잔한 연못에 물방울이 떨어지면, 물결이 지나갈 때 노란 오리는 어떻게 될까? 하나만 고르고 이유를 써 보자.

- ( ) 물결을 따라 바깥쪽으로 밀려간다
- ( ) 제자리에서 위아래로 움직인다
- ( ) 물방울이 떨어진 곳으로 끌려온다
- ( ) 전혀 움직이지 않는다

이유: ______________________________________________

**조작.**
1. `① 물결 연못` 탭에서 수면을 짧게 눌러 물방울을 떨어뜨린다.
2. `〰 흔적 보기`를 켠다.
3. `⚪ 물 알갱이 보기`를 켠다.
4. `🎥 보는 방향 처음대로`와 화면 끌기로 여러 방향에서 본다.
5. 물방울을 3번 이상 떨어뜨린다. `물결 세기`도 바꿔 본다.

**관찰.** 오른쪽 읽음값과 화면을 보고 채우자.

| 관찰할 것 | 내가 본 것 |
| --- | --- |
| 오리가 옆으로 움직인 거리 (cm) | |
| 오리의 움직임 흔적은 어떤 모양인가? | |
| 흰 물 알갱이는 어느 방향으로 움직이나? | |
| 물결(빨간 화살표)과 오리(초록 화살표)의 방향 | |

**설명. 왜 그럴까?** 위 관찰을 바탕으로 `매질`, `진동`이라는 말을 넣어 설명해 보자.

### 문항 2. 나뭇잎은 왜 흔들릴까? [예측 → 조작 → 관찰 → 설명]

**예측.** 멀리 있는 나뭇잎은 물방울을 떨어뜨리자마자 흔들릴까, 시간이 지나야 흔들릴까?

예측: ______________________________________________

**조작.** `🫧 잔잔하게 만들기`를 누른 뒤 `💧 물방울 하나 떨어뜨리기`를 한 번 누르고, 나뭇잎을 지켜본다. 못 봤으면 `🐢 느리게 ×0.25`를 켜서 다시 해 본다.

**관찰.** 나뭇잎 상태가 어떻게 바뀌는지 순서대로 쓰자.

( 잔잔함 ) → (　　　　　　) → (　　　　　　)

**설명. 왜 그럴까?** 물은 나뭇잎까지 오지 않았는데 나뭇잎이 흔들렸다. 물결파가 나뭇잎까지 전달한 것은 무엇일까? 우리 생활에서 같은 예를 하나 들어 보자.

## 2단계 ② 용수철 실험실

### 문항 4. 파장과 진폭 재기 [예측 → 조작 → 관찰 → 설명]

**예측.** 진폭만 크게 하면 파장도 길어질까? ( 길어진다 / 그대로다 / 짧아진다 )

**조작.**
1. `② 용수철 실험실` 탭에서 `⚙️ 자동으로 흔들기`, 용수철 팽팽함은 `보통`으로 둔다.
2. `진폭` 0.30 m, `주기` 1.20 초로 맞춘다.
3. `🏷 라벨 보기`를 켜고 `⏸ 일시정지`를 누른다.
4. 노란 자의 두 끝을 끌어 마루와 이웃한 마루에 붙여 가로 거리를 잰다.
5. 자를 진동의 중심과 마루에 붙여 세로 거리를 잰다.
6. `⏸`(재생)을 눌러 다시 움직이게 한 뒤, `주기`는 그대로 두고 `진폭`만 0.50 m로 바꿔 다시 재어 본다.

**관찰.**

| 진폭 슬라이더 | 마루~이웃한 마루 가로 거리 (m) | 진동의 중심~마루 세로 거리 (m) |
| --- | --- | --- |
| 0.30 m | | |
| 0.50 m | | |

### 문항 5. 주기와 진동수, 조건 맞추기 [예측 → 조작 → 관찰 → 설명]

**예측.** `주기`를 길게 하면 `진동수`(Hz)는 커질까, 작아질까? ( 커진다 / 작아진다 )

**조작.**
1. `주기` 슬라이더를 아래 값으로 바꾸고 옆의 `진동수` 읽음값을 쓴다.
2. 리본 그래프를 두 번 눌러 마루에서 다음 마루까지의 시간 차를 재 본다. (일시정지하면 쉬워요.)
