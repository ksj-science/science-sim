## 문항 1. 증발이 멈출까? (탭 ① 포화 상태 만들기)

**[예측]** 뚜껑이 닫힌 곳에서 물이 증발하면, 공기가 수증기로 가득 찬 뒤에는 어떻게 될까? 내 생각을 써 보자.

> ____________________________________________

**[조작]**
1. 탭 **① 포화 상태 만들기**를 누른다.
2. 기온 슬라이더를 **20 °C**에 맞춘다.
3. **▶ 증발 시작**을 누르고, '포화 상태'라고 뜰 때까지 기다린다.
4. 포화가 된 뒤에도 물 분자(공)와 화살표, 아래 두 막대(증발하는 양, 응결하는 양)를 잘 본다.

**[관찰]**

| 살펴볼 것 | 불포화일 때 | 포화 상태가 된 뒤 |
| --- | --- | --- |
| 수면에서 튀어 나가는 분자 | | |
| 두 막대(증발하는 양 / 응결하는 양) 길이 비교 | | |

**[설명]** 왜 그럴까? 포화 상태에서 물의 양이 더 이상 줄지 않는 까닭을 '증발'과 '응결'이라는 말을 써서 설명해 보자.

## 문항 2. 기온이 바뀌면? (탭 ① 포화 상태 만들기)

**[예측]** 기온이 높을수록 공기가 품을 수 있는 수증기의 양은 어떻게 될까?

> ____________________________________________

**[조작]**
1. 탭 ①에서 기온 슬라이더를 **10 °C**로 맞추고 **▶ 증발 시작**을 눌러 포화가 될 때까지 기다린다.
2. 포화가 되면 아래 칸에 '포화 수증기량'을 적는다.
3. 같은 방법으로 **15 °C**, **20 °C**에서도 해 본다. (기온을 바꾸면 상태점이 옆으로 움직여요.)
4. 기온을 높이면 상태가 어떻게 되는지 '불포화 상태'라는 말이 뜨는지도 본다.

**[관찰]**

| 기온(°C) | 포화 수증기량(g/kg) | 기온을 높이면 상태가 어떻게 바뀌었나 |
| --- | --- | --- |
| 10 | | |
| 15 | | |
| 20 | | |

**[설명]** 왜 그럴까? 기온과 포화 수증기량의 관계를 '포화 수증기량 곡선'이라는 말을 써서 설명해 보자.

## 문항 3. 이 공기는 포화일까? (탭 ③ 공기 판정하기)

**[예측]** 수증기량이 7 g/kg으로 같은 공기 (가) 10 °C, (나) 20 °C가 있다. 둘 다 같은 상태일까?

> ____________________________________________

**[조작]**
1. 탭 **③ 공기 판정하기**를 누른다.
2. 그래프의 점(●)을 끌어 (가)의 기온과 수증기량 자리에 놓는다. (가로축은 기온, 세로축은 수증기량이에요.)
3. **포화 상태** 또는 **불포화 상태**를 고르고 **✔ 확인**을 누른다.
4. **다음 공기 ▶**를 눌러 (나)도 해 본다.

**[관찰]**

| 공기 | 수증기량(g/kg) | 기온(°C) | 상태 |
| --- | --- | --- | --- |
| (가) | | | |
| (나) | | | |

**[설명]** 왜 그럴까? 같은 수증기량인데 상태가 다른 까닭을 '포화 수증기량'이라는 말을 써서 설명해 보자.

## 문항 4. 이슬점을 찾아라 (탭 ② 이슬점과 응결량)

**[예측]** 30 °C이고 수증기량이 7.0 g/kg인 공기를 식히면, 몇 °C에서 물방울이 처음 생길까?

> ____________________________________________ °C

**[조작]**
1. 탭 **② 이슬점과 응결량**을 누른다.
2. **처음 기온**을 30 °C, **처음 수증기량**을 7.0 g/kg으로 맞춘다.
3. **❄ 냉각 시작**을 누른다. 점이 곡선에 닿으면 '이슬점!'이 나타난다.
4. 물방울이 처음 생기는 때를 놓쳤다면 **−1 °C**, **+1 °C** 단추로 다시 찾는다.

**[관찰]**

| 처음 기온(°C) | 처음 수증기량(g/kg) | 물방울이 처음 생긴 기온(이슬점, °C) |
| --- | --- | --- |
| 30 | 7.0 | |

**[설명]** 왜 그럴까? 이슬점이 무엇인지 '포화 상태'라는 말을 써서 설명해 보자.

> ____________________________________________

## 문항 5. 얼마나 응결했을까? (탭 ② 이슬점과 응결량)

**[예측]** 30 °C, 14.0 g/kg인 공기를 이슬점보다 더 낮게 식히면 물방울은 점점 늘어날까?

> ____________________________________________

**[조작]**
1. **📘 교과서 예: 30 °C·14.0 g/kg** 단추를 누른다.
2. **❄ 냉각 시작**으로 식히다가, **지금 기온**이 5 °C가 되게 맞춘다. (**−1 °C** 단추나 지금 기온 슬라이더를 써요.)
3. 화면 아래 '물 장부'를 읽는다.

**[관찰]**

| 지금 기온(°C) | 공기 속 수증기(g) | 맺힌 물(g) | 합(g) |
| --- | --- | --- | --- |
| 20 | | | |
| 10 | | | |
| 5 | | | |

**[설명]** 왜 그럴까? 응결량을 구하는 식을 '처음 수증기량'과 '포화 수증기량'이라는 말을 써서 써 보자. 그리고 물 장부의 합이 늘 같은 까닭도 써 보자.

## 문항 6. 이슬점은 무엇이 정할까? (탭 ② 이슬점과 응결량)

**[예측]** 수증기량이 같은 공기라도 처음 기온이 높으면 이슬점도 높을까?

> ____________________________________________

**[조작]**
1. 탭 ②에서 **처음 수증기량**을 14.0 g/kg으로 둔다.
2. **처음 기온**을 25 °C로 하고 이슬점이 나올 때까지 **❄ 냉각 시작**을 누른다.
3. 처음 기온을 30 °C, 35 °C로 바꿔 같은 일을 한다. (**이슬점 기록** 표에 쌓여요.)
4. 이번에는 처음 기온을 30 °C로 두고 **처음 수증기량**만 바꿔 한 번 더 해 본다.

**[관찰]**

| 처음 기온(°C) | 처음 수증기량(g/kg) | 이슬점(°C) |
| --- | --- | --- |
| 25 | 14.0 | |
| 30 | 14.0 | |
| 35 | 14.0 | |
| 30 | (내가 고른 값) | |

**[설명]** 왜 그럴까? 이슬점이 처음 기온이 아니라 무엇에 따라 정해지는지 써 보자.
