# 채팅으로 만든 시뮬레이터

Claude 채팅에서 만든 한 파일짜리 시뮬레이터입니다(원본: 개인 구글 드라이브 `시뮬레이터` 폴더, 2026-11-22 기준).
교사용 대시보드(`teacher.html`)에 **💬 채팅** 배지로, 클로드 코드로 만든 `sims/<ID>/`는 **🛠 클로드 코드** 배지로 구분됩니다.

- 단원 ID: `chat-<파일 이름>` (예: `sim_annual_sun.html` → `chat-annual-sun`), 웹앱 주소 `…/exec?unit=chat-annual-sun`
- 목록·상태는 `units.json`(`"source": "chat"`)
- 화면 안의 '정답 확인'은 학생 스스로 확인하는 연습용 피드백이며, 채점용 정답은 학교 구글 시트에만 둡니다.
