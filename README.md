# science-sim — 중학교 과학 시뮬레이터

하남중학교 과학 수업용 시뮬레이터 모음입니다.

- 사이트: https://ksj-science.github.io/science-sim/
- 시뮬레이터는 누구나 자유롭게 수업에 쓰실 수 있습니다.

## 폴더
| 폴더·파일 | 내용 |
| --- | --- |
| `sims/<단원ID>/` | 단원별 시뮬레이터 (단원ID = `개정연도-학년-대단원-중단원-순번`, 예: `22-2-3-1-01`) |
| `lib/` | 공통 스타일(`sim.css`)과 웹앱 통신(`sim-bridge.js`) |
| `units.json` | 사이트 첫 화면 목록 |
| `단원설계서/` | 단원별 설계서 |
| `shell/` | 학교 계정 Apps Script 웹앱(문항·채점·기록) 코드 |

정답과 학생 기록은 이 저장소가 아니라 학교 구글 시트에만 있습니다.
